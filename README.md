# ShadeCore Documentation

This directory contains the official documentation for **ShadeCore / Schengine**.

The docs are intentionally segmented to serve **three distinct audiences**:

1. **SDK / Engine Users**  
   Developers embedding ShadeCore into tools or extending the engine.

2. **Instrument Builders**  
   Developers creating interactive video instruments using graphs, shaders, and OSC.

3. **Players / Explorers**  
   Users running examples, experimenting with OSC, and learning what is possible.

Each section below is scoped to one of these audiences. Documentation avoids mixing conceptual layers to keep the system understandable and maintainable.
